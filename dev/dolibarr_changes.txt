
This file describes the changes made on external libraries to fix some bugs, after they were included
in Dolibarr external vendor dir (htdocs/includes).

How to read this file
---------------------
Each library has a header block:

    ####################################################################################################
    # LIBRARY : name of the library
    # PATH    : root directory of the library
    ####################################################################################################

Then each change is described with:

    ==> FILE   : file modified (relative to the library PATH, unless a full path is given)
        REASON : why the change was made
        DIFF   :
            - line(s) of the upstream version (to remove)
            + line(s) of the Dolibarr version (to add)

For all libraries, also search the code for the tag "@CHANGE" (and "DOL CHANGE", "LDR CHANGE") to find
modified lines.

VERSION : 6.11.4 (upgraded from 6.7.5 in 2026-09).

NOTES   :
  - As of this version, upstream's own composer.json marks TCPDF "abandoned" in favor of
    tecnickcom/tc-lib-pdf. It is kept for now since Dolibarr (and the bundled TCPDI fork) still relies
    on TCPDF-specific internals. A migration off TCPDF entirely would be a separate, much larger effort.
  - Upstream dropped tcpdf_parser.php and tcpdf_import.php from the package in this version.
    tcpdf_parser.php (TCPDF_PARSER) is still required by htdocs/core/lib/pdf.lib.php::pdf_getEncryption(),
    so our unmodified copy of the 6.7.5 file is kept alongside the upgraded library.
    tcpdf_import.php was unused anywhere in Dolibarr and was not kept.
